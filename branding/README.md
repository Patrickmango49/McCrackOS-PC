# Branding Assets

The first visual direction is a clean, premium dark desktop with restrained cyan accents.

- The original abstract wallpaper is installed at `/usr/share/backgrounds/mccrack-cos.svg`.
- KDE user defaults are staged under `config/includes.chroot/etc/skel/.config/`.
- SDDM currently uses the stock Breeze theme until a branded login theme is ready.

Future approved assets can be placed in:
- `logos/`
- `wallpapers/`
- `icons/`
- `boot/`
- `login/`

Keep original source artwork where practical and document asset licenses or attribution when applicable.
